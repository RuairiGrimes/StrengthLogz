How to set up Google Sheets (one-time, ~5 min)
  1. Go to Google Cloud Console and create a project (any name).
  2. Enable the Google Sheets API for that project.
  3. Go to IAM → Service Accounts, create one, then Keys → Add key → JSON. Save the file somewhere safe.
  4. Create a blank Google Sheet and Share it with the service account's email (shown above once you pick the key) as Editor.
  5. Paste the sheet URL here, pick the key file and press Connect. Tabs Workouts, Sets and Exercises are created automatically.
